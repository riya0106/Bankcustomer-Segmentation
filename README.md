# Bank Customer Segmentation Using Clustering

## Overview

This project uses unsupervised machine learning to segment bank customers based on demographic, financial, and campaign-related features. The goal was to identify meaningful customer groups that can support targeted marketing, personalized banking products, and better customer relationship strategies.

## Problem

Banks collect large amounts of customer data, but raw data alone does not always explain customer behavior. This project explores how clustering can uncover hidden customer segments and help financial institutions understand different client profiles.

## Project Workflow

- Explored customer demographics and financial behavior
- Checked for missing values and data quality issues
- Encoded categorical variables
- Standardized numerical features
- Used the Elbow Method to identify the optimal number of clusters
- Applied K-Means Clustering
- Applied Agglomerative Clustering
- Compared cluster results and interpreted customer segments

## Clustering Methods Used

- K-Means Clustering
- Agglomerative Hierarchical Clustering

## Key Findings

- The Elbow Method suggested three meaningful customer segments.
- K-Means and Agglomerative Clustering produced similar segmentation patterns.
- Customer groups were influenced by factors such as age, account balance, loans, and campaign engagement.
- Three main customer profiles were identified:
  - Established Investors
  - Mid-Level Professionals
  - Young Budget Savers

## Business Impact

This project demonstrates how customer segmentation can help banks improve marketing strategy and customer personalization.

The insights can support:

- Targeted marketing campaigns
- Personalized financial products
- Customer relationship management
- Improved resource allocation
- Financial inclusion strategies

Because customer data can be sensitive, segmentation should be used responsibly with attention to privacy, fairness, and transparency.
